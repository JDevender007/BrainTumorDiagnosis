1. PROJECT OVERVIEW
==============================================================================

Research Question:
  Does segmentation-guided tumor-aware representation learning improve
  classification generalization, robustness, calibration, and
  interpretability compared with conventional image-level classification?

Proposed Model: TumorAwareMultiTaskNet
  - MRI -> Shared DenseNet121 Encoder -> [Global Features, Segmentation Features]
  - Segmentation -> Tumor Mask -> Tumor Region Pooling
  - Global Features + Tumor Features -> Cross-Attention Fusion -> Classification

12 Novel Contributions:
  1. Tumor-aware multi-task architecture with cross-attention fusion
  2. Segmentation-guided feature extraction for classification
  3. MC-Dropout uncertainty estimation (10 forward passes)
  4. MRI Robustness Retention Score (MRRS) metric
  5. Cross-dataset validation (BraTS-2025 internal, BRISC-2025 external)
  6. 27 corruption types x severity levels robustness testing
  7. Information-theoretic uncertainty decomposition
  8. Temperature scaling calibration
  9. Grad-CAM localization interpretability
  10. Multi-seed statistical validation (3 seeds, 95% CI)
  11. 7-backbone architecture comparison
  12. Real-time inference efficiency analysis

Output Folder (all results):
  outputs/research_experiments/all_outputs/
  Contains: 12 table PNGs, 16 figure PNGs, 2 summary PNGs, 5 JSON-as-PNGs,
            5 JSON files = 42 files total

4. ARCHITECTURE & MODELS
==============================================================================

BACKBONES COMPARED (7 total):
  1. CNN-2D (project baseline): 0.3M params, val_f1=0.9526
  2. DenseNet121 (SELECTED): 7.97M params, val_f1=0.9795, 30.4MB
  3. ResNet50: 23.5M params, val_f1=0.9704, 90.0MB
  4. EfficientNetV2-S: 21.3M params, val_f1=0.9806, 81.2MB
  5. ConvNeXt-Tiny: 28.6M params, val_f1=0.9742, 109.0MB
  6. Swin-T: 28.3M params, val_f1=0.9709, 107.8MB
  7. ViT-B/16: 86.1M params, val_f1=0.9752, 327.2MB

DenseNet121 selected as best trade-off between accuracy and efficiency.

PROPOSED MODEL: TumorAwareMultiTaskNet
  Total Parameters: 9,034,416 (9.03M)
  Model Size: 34.46 MB
  Architecture Components:
    - Encoder: DenseNet121 (pretrained on ImageNet)
    - Global Pooling: AdaptiveAvgPool2d(1) + BatchNorm1d
    - Tumor Region Pool: SpatialAttention + AdaptiveAvgPool2d + Linear
    - Attention Fusion: Cross-attention (global_dim, tumor_dim -> fusion_dim)
    - Classifier: Linear(256) -> BN -> ReLU -> Dropout -> Linear(128) -> ReLU -> Dropout -> Linear(4)
    - Segmentation Head: Conv decoder with upsampling
    - Uncertainty Head: MC Dropout + Linear

  TumorAwareConfig:
    backbone: "densenet121"
    pretrained: True
    num_classes: 4
    segmentation_classes: 4
    dropout: 0.3
    fusion_dim: 256
    use_attention_fusion: True
    use_segmentation_head: True
    use_uncertainty_head: True
    mc_dropout_passes: 10

  Key Sub-modules:
    - SpatialAttention: Conv(2->1, k=7) + Sigmoid (avg+max pooling)
    - ChannelAttention: SE-style (avg_pool + max_pool + FC)
    - TumorRegionPool: SpatialAttention + AdaptiveAvgPool + FC
    - AttentionFusion: Projects both to fusion_dim, softmax attention, LayerNorm
    - SegmentationHead: Conv(128) -> Upsample(4x) -> Conv(64) -> Upsample(2x) -> Conv(num_classes)
    - UncertaintyHead: Dropout + Linear

  Forward Pass:
    1. x -> encoder -> feature_map (via hook) + features
    2. features -> global_pool -> global_bn -> global_feat
    3. feature_map -> tumor_pool(+ seg_mask) -> tumor_feat
    4. global_feat + tumor_feat -> attention_fusion -> fused
    5. fused -> classifier -> logits
    6. feature_map -> seg_head -> seg_logits (optional)
    7. fused -> uncertainty_head -> uncertainty_logits (optional)

  MC Dropout Uncertainty:
    - Set model to train() mode
    - Run 10 forward passes with dropout active
    - Compute: mean_probs, predictive_variance, predictive_entropy,
      mutual_info, epistemic_uncertainty, aleatoric_uncertainty

17. HOW THIS PROJECT WORKS (END-TO-END PIPELINE)
==============================================================================

This section explains the complete workflow of the project — how data flows
from raw MRI images through training, evaluation, and finally into a
research paper with tables and figures.


--- STEP 1: DATA LOADING & PREPROCESSING ---

Raw MRI brain images (JPEG/PNG, RGB) are organized by diagnosis class:

  data/raw/classification/
    Train/
      glioma/        <- images of glioma tumors
      meningioma/    <- images of meningioma tumors
      no tumor/      <- images of healthy brains
      pituitary/     <- images of pituitary tumors
    Test/
      (same 4 folders, official held-out test set)

The dataset loader (datasets/classification.py) does:
  1. Scans all subdirectories, assigns numeric labels:
       glioma=0, meningioma=1, no tumor=2, pituitary=3
  2. Creates list of (image_path, label) tuples
  3. Splits 85% train / 15% validation (stratified by class)
  4. Returns DataLoaders with batch_size=8

Each image goes through preprocessing:
  1. Resize to 224x224
  2. Convert to tensor (3 channels, float32, 0-1 range)
  3. Normalize with ImageNet statistics:
       mean = [0.485, 0.456, 0.406]
       std  = [0.229, 0.224, 0.225]

This ensures compatibility with pretrained ImageNet backbones.


--- STEP 2: MODEL ARCHITECTURE (TumorAwareMultiTaskNet) ---

The proposed model has 3 main branches working together:

INPUT: Brain MRI image (batch of 8, 3x224x224)

    +-----------+
    | MRI Image |
    +-----+-----+
          |
    +-----v-----------+
    | DenseNet121     |  <- Shared encoder (pretrained on ImageNet)
    | Encoder         |     Extracts hierarchical features
    | (frozen early   |
    |  layers)        |
    +---+-------+-----+
        |       |
  Features    Feature Map
  (1024-d)    (1024x7x7)
        |       |

--- STEP 3: TRAINING PROCESS ---

Training happens in multiple phases:

PHASE 1 — Baseline DenseNet121:
  1. Load pretrained DenseNet121
  2. Replace final FC layer: 1024 -> 4 classes
  3. Train with AdamW optimizer (lr=0.0001, weight_decay=0.0001)
  4. Cosine annealing LR schedule
  5. Mixed precision (AMP) for speed on 4GB GPU
  6. Early stopping: if val_f1 doesn't improve for 5 epochs, stop
  7. Save best checkpoint (best.pt) and training history
  Result: val_f1 = 0.9624

PHASE 2 — Proposed TumorAwareMultiTaskNet:
  1. Initialize TumorAwareMultiTaskNet with DenseNet121 encoder
  2. Train with 3 loss components simultaneously:
       Total Loss = 1.0 * CrossEntropy(labels, logits)
                   + 0.5 * DiceLoss(seg_logits, seg_targets)
                   + 0.1 * UncertaintyLoss
  3. Gradient accumulation (2 steps) to simulate larger batch
  4. Gradient clipping (max_norm=1.0) to prevent explosions
  5. Train for 30 epochs
  6. Save best model based on val_f1
  Result: val_f1 = 0.9847 (best epoch 26)

KEY TRAINING DETAILS:
  - Gradient accumulation: because 4GB GPU can't fit batch_size=16
  - Label smoothing: 0.1 (prevents overconfidence)
  - CosineAnnealing: LR decays from 0.0001 to near 0 over 30 epochs
  - Mixed precision: uses float16 for forward pass, float32 for gradients


--- STEP 4: EVALUATION PIPELINE ---

After training, the model is evaluated on multiple dimensions:

4A. CLASSIFICATION PERFORMANCE
    - Feed all 1,857 test images through the model
    - Compute: accuracy, F1, precision, recall, confusion matrix
    - Per-class analysis (glioma, meningioma, no tumor, pituitary)
    - ROC curves and precision-recall curves for each class
    Result: 96.45% accuracy, 98.47% F1

4B. UNCERTAINTY ESTIMATION (MC Dropout)
    - Put model in train() mode (dropout active)
    - Run 10 forward passes per image
    - Each pass produces different predictions due to dropout
    - Compute from the 10 predictions:
        Mean confidence: how sure the model is on average
        Predictive entropy: total uncertainty
        Mutual information: epistemic (model) uncertainty
        Predictive variance: spread of predictions
    - Analyze: correct vs incorrect predictions
    Result: Correct predictions have higher confidence (0.8843 vs 0.8232)

4C. CALIBRATION
    - Compare predicted confidence with actual accuracy
    - A perfectly calibrated model: confidence 90% = accuracy 90%
    - Metrics:
        ECE (Expected Calibration Error): 0.0855
        MCE (Maximum Calibration Error): 0.5603
        Brier Score: 0.0736 (lower is better)
        NLL (Negative Log Likelihood): 0.2172
    - Temperature scaling to improve calibration
    - Reliability diagram shows calibration visually

4D. ROBUSTNESS (27 Corruption Types)
    - Apply 27 different image corruptions at multiple severity levels:
        Families: Gaussian Noise, Salt & Pepper, Gaussian Blur,
                  Motion Blur, Defocus Blur, Brightness, Contrast,
                  Saturate, JPEG Compression, Pixelate, Fog, Frost,
                  Elastic Transform, Zoom Blur, Spatter,
                  Glass Blur, Shot Noise, Impulse Noise, etc.
    - Severity levels: 0.1 (mild) to 1.0 (severe)
    - Test accuracy under each corruption
    - MRRS = mean accuracy / clean accuracy = 0.7512
    - Worst: contrast_0.5 drops accuracy to 22.4%
    - Best: rotation_5.0 barely affects accuracy (96.0%)

4E. CROSS-DATASET VALIDATION
    - Test on internal BraTS dataset (1,857 images): 96.45%
    - Test on external BRISC-2025 dataset (1,000 images): 97.70%
    - External is BETTER (accuracy drop = -1.25%)
    - Shows the model generalizes well to completely different data

4F. EFFICIENCY ANALYSIS

--- STEP 6: GRAD-CAM INTERPRETABILITY ---

Grad-CAM (Gradient-weighted Class Activation Mapping) visualizes
which regions of the image the model focuses on:

  1. Take the feature maps from the last convolutional layer
  2. Compute gradients of the predicted class w.r.t. feature maps
  3. Weight feature maps by mean gradient (importance)
  4. Sum weighted feature maps -> heatmap
  5. Overlay heatmap on original image

Shows:
  - Model focuses on tumor regions (not background)
  - Glioma: model looks at the tumor mass
  - Meningioma: model focuses on the dural attachment
  - Pituitary: model looks at the sellar region

--- KEY DIFFERENTIATORS FROM BASELINE ---

The baseline (standard DenseNet121) does:
  Image -> DenseNet121 -> Pool -> FC -> 4 classes

The proposed model adds:
  Image -> DenseNet121 -> Feature Map
                |              |
                |         Tumor Region Pool
                |         (attention-weighted)
                |              |
                +-> Attention Fusion <-+
                      |
                    Fused
                      |
               +------+------+
               |      |      |
             Class   Seg   Uncertainty

Why this helps:
  1. Tumor region pooling focuses on the tumor area, not background
  2. Cross-attention fusion lets the model weigh global vs tumor features
  3. Segmentation head provides auxiliary supervision (forces model to
     learn tumor anatomy)
  4. Uncertainty head provides confidence estimates (critical for
     clinical deployment)
  5. The combination improves F1 from 96.24% -> 98.47% (+2.23%)
  6. External validation improves from ~96% -> 97.70%
  7. Robustness: MRRS = 0.7512 (model retains 75% accuracy under
     corruption)


--- INFERENCE PIPELINE (Clinical Use) ---

For real clinical deployment:

  1. Patient MRI arrives
  2. Preprocess: resize 224x224, normalize
  3. Feed to TumorAwareMultiTaskNet
  4. Run 10 forward passes (MC Dropout) for uncertainty
  5. Output:
       - Diagnosis: glioma/meningioma/no_tumor/pituitary
       - Confidence: 88.5% mean confidence
       - Uncertainty: epistemic + aleatoric breakdown
       - Grad-CAM heatmap: shows WHERE the model is looking
       - Segmentation mask: highlights tumor region
  6. If uncertainty > threshold -> flag for radiologist review
  7. Total time: ~49ms per image (20.6 FPS real-time)

19. HOW TO TEST WITH A NEW DATASET
==============================================================================

To test the trained model on your own dataset:

--- STEP 1: ORGANIZE YOUR DATA ---

Your dataset must have this structure:

  your_dataset/
  ├── glioma/
  │   ├── image1.jpg
  │   ├── image2.png
  │   └── ...
  ├── meningioma/
  │   ├── image1.jpg
  │   └── ...
  ├── no_tumor/
  │   ├── image1.jpg
  │   └── ...
  └── pituitary/
      ├── image1.jpg
      └── ...

Requirements:
  - 4 folders: glioma, meningioma, no_tumor, pituitary
  - Images: RGB JPEG/PNG (any size, will be resized to 224x224)
  - No sub-folders within class folders
  - Supported extensions: .jpg, .jpeg, .png, .bmp, .tiff

--- STEP 2: WRITE A LOADING SCRIPT ---

Create a file called test_new_dataset.py:

  import torch
  import torch.nn.functional as F
  from pathlib import Path
  from PIL import Image
  from torchvision import transforms
  from torch.utils.data import DataLoader, Dataset
  from models.tumor_aware import TumorAwareMultiTaskNet, TumorAwareConfig

  CLASS_NAMES = ["Glioma", "Meningioma", "No Tumor", "Pituitary"]
  CLASS_TO_IDX = {name: i for i, name in enumerate(CLASS_NAMES)}

  class NewDataset(Dataset):
      def __init__(self, root_dir, transform=None):
          self.root = Path(root_dir)
          self.transform = transform
          self.samples = []
          for class_name in CLASS_NAMES:
              class_dir = self.root / class_name.lower().replace(" ", "_")
              if not class_dir.exists():
                  class_dir = self.root / class_name.lower()
              if class_dir.exists():
                  for img_path in class_dir.glob("*"):
                      if img_path.suffix.lower() in (".jpg", ".jpeg", ".png"):
                          self.samples.append((img_path, CLASS_TO_IDX[class_name]))

      def __len__(self):
          return len(self.samples)

      def __getitem__(self, idx):
          path, label = self.samples[idx]
          image = Image.open(path).convert("RGB")
          if self.transform:
              image = self.transform(image)
          return image, label

  # Load model
  config = TumorAwareConfig(backbone="densenet121")
  model = TumorAwareMultiTaskNet(config)
  checkpoint = torch.load(
      "outputs/research_experiments/proposed_model/best.pt",
      map_location="cpu",
      weights_only=False
  )
  model.load_state_dict(checkpoint["model_state_dict"])
  model.eval()

  # Load data
  transform = transforms.Compose([
      transforms.Resize((224, 224)),
      transforms.ToTensor(),
      transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225]),
  ])

  dataset = NewDataset("path/to/your_dataset", transform=transform)
  loader = DataLoader(dataset, batch_size=8, shuffle=False)

  # Evaluate
  correct = 0
  total = 0
  with torch.no_grad():
      for images, labels in loader:
          outputs = model(images)
          if isinstance(outputs, dict):
              preds = outputs["logits"].argmax(dim=1)
          else:
              preds = outputs.argmax(dim=1)
          correct += (preds == labels).sum().item()
          total += labels.size(0)

  print(f"Accuracy: {correct/total*100:.2f}% ({correct}/{total})")

--- STEP 3: RUN IT ---

  python test_new_dataset.py

--- STEP 4: OPTIONAL - ADD UNCERTAINTY ---

  # Add MC Dropout uncertainty estimation
  model.train()  # Keep dropout active
  num_passes = 10
  all_preds = []

  with torch.no_grad():
      for images, labels in loader:
          batch_preds = []
          for _ in range(num_passes):
              outputs = model(images)
              if isinstance(outputs, dict):
                  probs = F.softmax(outputs["logits"], dim=1)
              else:
                  probs = F.softmax(outputs, dim=1)
              batch_preds.append(probs)
          # Stack predictions: [num_passes, batch_size, num_classes]
          stacked = torch.stack(batch_preds)
          mean_probs = stacked.mean(dim=0)
          entropy = -(mean_probs * torch.log(mean_probs + 1e-10)).sum(dim=1)
          preds = mean_probs.argmax(dim=1)

          for i in range(len(labels)):
              print(f"Image {total+i}: "
                    f"Pred={CLASS_NAMES[preds[i]]}, "
                    f"Conf={mean_probs[i].max():.3f}, "
                    f"Entropy={entropy[i]:.3f}")
